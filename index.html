TREE

Build branching structures with nodes, animate them with sliders, then turn them into printable meshes.

Graph

Double-click the canvas to search for a node, or use the palette. Drag from a slot to connect. Right-click a node for options. Number widgets drag left and right; click one to type a value.

Widgets and pins

Every parameter starts as a widget on the node. Drop a link straight onto the widget row and it becomes an input pin, so a Slider, an LFO or a field can drive it. Right-click a node and use Inputs to flip any parameter back and forth.

Flow

Root makes trunks. Branch sprouts branches from the joints of whatever came before it, or from an explicit at selection. Select picks joints of a branch set. Rotate / Translate / Scale / Size change the selected joints. Finish with Preview, Tubes or Isosurface.

A transform with no selection plugged in applies to the branches made by the nearest upstream Root or Branch. Structure is shared: every Branch node connected to the skeleton adds to it; the pose comes only from the transforms on the path to the output.

Surfaces

Loft spans a surface across a set of branches (the ribs), as adjacent pairs or as one patch across the whole set. Warp pushes the lofted points along the surface normal and the two surface directions with expressions over u v iu iv nu nv x y z r patch patches time. Curve Tubes extrudes tubes along the lofted rows or columns, which is how a veined membrane is made. Surface meshes the patches as a sheet, solid or open. Lofted curves can also go straight into the Isosurface's curves input, which blobs the whole membrane and the branches into one mesh.

Joint attributes

A field is evaluated once per joint. Expressions may also use sin cos abs noise(x,y,z) hash(n) clamp mix smoothstep and the inputs a b c d.

Reuse

Select nodes and press Save group in the palette (or ctrl+shift+s) to store them as a named preset. Click the preset to drop another copy into the graph, wired the same way. Frame (ctrl+g) draws a titled box around a selection. Export and import the whole library as JSON.

Printing

Tubes gives one closed shell per branch with ball caps, fast enough to leave live. Isosurface unions everything into a single watertight mesh, following the same smoothed curve the tubes use; it runs in a worker. Plug a mesh into its points input and give it a point radius to shrink-wrap that geometry too, or lofted curves into curves for a much cleaner result. Export OBJ or STL from the node or the preview bar, and set the export scale to your units.
